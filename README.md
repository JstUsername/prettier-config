# @web-bee-ru/prettier-config

Common Prettier configuration. Compatible with another prettier configs.

## Installation

Install the module

```bash
npm install --save-dev prettier @trivago/prettier-plugin-sort-imports @web-bee-ru/prettier-config
```

## Usage

Add this to your package.json file:

```json
"prettier": "@web-bee-ru/prettier-config"
```

Alternatively, add this to `.prettierrc` file:

```
"@web-bee-ru/prettier-config"
```

Or add this to `.prettierrc.js` file:

```js
import webbeePrettierConfig from "@web-bee-ru/prettier-config"
```
